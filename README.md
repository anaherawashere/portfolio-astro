# Anahera's Portfolio

A simple, fast, and accessible personal portfolio built with [Astro](https://astro.build/) and styled using [Tailwind CSS](https://tailwindcss.com/). This site showcases my web development projects, skills, and experience.

This portfolio was inspired by the [Astro Aria Template](https://github.com/ccbikai/astro-aria).

## Live Site

You can view the deployed site here: [anahera.co](https://anahera.co/)

## Tech Stack

- [Astro](https://astro.build/) – Static site generator
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- [TypeScript](https://www.typescriptlang.org/) – Typed JavaScript

## Features

- Mobile-responsive layout
- Clean, semantic HTML
- Accessible navigation and content
- Project cards linking to live demos and code

## Getting Started

To run locally:

```bash
git clone https://github.com/anaherawashere/portfolio-astro.git
cd portfolio-astro
npm install
npm run dev
```

Then visit http://localhost:4321 in your browser.
